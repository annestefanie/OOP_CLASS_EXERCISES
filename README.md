#  Object-Oriented Programming (OOP) Exercises

Here, I have compiled all the exercises from the university's Object-Oriented Programming (OOP) course. The main goal is to practice object-oriented programming and improve my logical skills.

---

## How to Run the Projects
Since each exercise is organized into its own folder, you can run any specific exercise using your terminal or an IDE (like VS Code, IntelliJ, or Eclipse).

### Running via Terminal:
1. Open your terminal and navigate to the specific exercise folder you want to run (for example, Exercise 3):

```bash
cd Exercise-03-Product-Management
```

2. Compile the Java files:

```bash
javac *.java
```

3. Run the main class:

```bash
java Main
```

## Technologies Used
Java (JDK 8+)

**Concepts**: Procedural logic, Control structures, Object-Oriented Programming (OOP), Encapsulation, and State Management.
