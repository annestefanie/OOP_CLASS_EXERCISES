<h3>Exercise 1</h3>

<h4>Smart Multiplication Table</h4>
<p>
  <strong>Objective:</strong>
  To practice reading data, using the for/while loop, simple mathematical operators, the modulus operator (%), and the if/else conditional statement.
</p>
<p>
  <strong>Problem Statement:</strong>
  Write a Java program that prompts the user to enter a positive integer. The program should calculate and display the multiplication table for that number from 1 to 10. However, the program has three additional rules:
  If the user enters a negative number, the program should display an error message: "Invalid number. Please enter a number greater than zero."
  When printing the multiplication table, the program must indicate, next to each result, whether that value is “Even” or “Odd.”
  The program must run indefinitely and display multiplication tables until the user enters 0 to exit.
</p>
