<h3>Exercise 2</h3>

<h4>ATM Simulator</h4>
<p>
  <strong>Objective:</strong>
   Practice flow control using a while (or do-while) loop, multiple conditional statements (switch or if/else), assignment operators (+=, -=), and output formatting.
</p>
<p>
  <strong>Problem Statement:</strong>
  Create a simple ATM simulator in Java. The user starts with an initial balance of R$ 500.00. The program should display a menu with the following options: 
  <br>
  1 - Check Balance 2 - Make a Deposit 3 - Make a Withdrawal 4 - Exit
</p>
